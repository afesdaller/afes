# Sytnikov Afes Igor | Interactive Portfolio

This is my personal portfolio website built with **Next.js 16** and **TypeScript**. It features high-performance animations, creative interactive elements, and a unique design inspired by ancient scrolls.

## 🚀 Technologies Used

- **Next.js 16 (App Router)**: Modern React framework with server-side rendering.
- **TypeScript**: Static typing for robust code.
- **Framer Motion (motion/react)**: Advanced UI animations and page transitions.
- **PixiJS**: Hardware-accelerated 2D graphics for background effects.
- **Next-intl**: Internationalization support for English and Ukrainian languages.
- **Tailwind CSS 4**: Utility-first CSS framework for rapid styling.

## ✨ Key Features

- **Unique Scroll UI**: A custom-built, responsive scroll component that expands dynamically with content.
- **Interactive Canvas Effects**: Dynamic particle systems (CanvasDust) for an immersive atmosphere.
- **Modern SEO**: Dynamic metadata generation for optimized search engine visibility and social media sharing.
- **Responsive Design**: Fully adapted for mobile and desktop devices.

## 🛠 Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
